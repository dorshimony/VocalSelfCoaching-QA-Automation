# VocalSelfCoaching – QA Automation Project

פרויקט אוטומציה לבדיקת אפליקציית פיתוח הקול VocalSelfCoaching.

נכתב ב־Python עם Playwright ו־Pytest, לפי Page Object Model.

**האתר הנבדק:** https://dorselfvocalcoach.netlify.app

---

## מה כל קובץ עושה

### pages/base_page.py
מחלקת הבסיס. מקבלת את אובייקט ה־page של Playwright ומחזיקה את הפעולות
המשותפות לכל הדפים: לחיצה, קריאת טקסט, בדיקת נראות, ספירת אלמנטים, המתנה ורענון.
כל שאר הדפים יורשים ממנה ומשתמשים ב־`super().__init__(page)`.

### pages/main_page.py
הכותרת העליונה והניווט. מחזיק את שם האפליקציה, כותרת המשנה,
ואת ארבע הלשוניות. מאפשר לפתוח לשונית לפי שם ולבדוק איזה עמוד מוצג.

### pages/vocal_test_page.py
עמוד המבחן הקולי, שלושה שלבים: מסך פתיחה עם בחירת מין ובדיקת מיקרופון,
מסך הרצת הסולמות עם כפתורי עצירה וביטול, ומסך תוצאות עם מדדי אוויר ולחץ,
טבלה ובחירת אבחנה.

### pages/exercises_page.py
עמוד התרגילים. מחזיק את מסך הנעילה, שורת האבחנה, התוכנית האישית,
בורר תו ההתחלה, כפתורי השמעת טון ייחוס, ומאגר כל התרגילים.

### pages/vowels_page.py
עמוד ההגייה המיטבית. מסך פתיחה, מסך הרצה עם חמש ההגיות,
וטבלת תוצאות עם המלצה לכל טווח.

### pages/progress_page.py
עמוד ההתקדמות. אריחי הסיכום, גרף שבעת הימים ויומן האימונים.

### conftest.py
ההגדרות המשותפות לכל הבדיקות. שלושה דברים:
כתובת האפליקציה שניתן לשנות בלי לגעת בקוד, הפעלת הדפדפן עם מיקרופון מדומה
כדי שאפשר יהיה לבדוק את המבחן הקולי, ו־fixture שפותח את האפליקציה ומנקה
נתונים שמורים לפני כל בדיקה.

## התקנה

```
pip install -r requirements.txt
playwright install chromium
```

## הרצה

הרצת כל הבדיקות:

```
pytest
```

הרצת קובץ בודד:

```
pytest tests/test_vocal_test_flow.py
```

הרצה עם דפדפן גלוי, כדי לראות מה קורה:

```
pytest --headed
```

## הרצה מול עותק מקומי

ברירת המחדל היא האתר החי. כדי לבדוק גרסה לפני העלאה:

Windows:
```
set APP_URL=http://localhost:8000/index.html
pytest
```

Mac / Linux:
```
export APP_URL=http://localhost:8000/index.html
pytest
```

כל 20 הבדיקות עוברות.

## באגים

חמישה באגים נמצאו, אומתו, תוקנו, וכל אחד מכוסה בבדיקת רגרסיה.

- `BUG_REPORT.html` — הדוח המפורט, עם שלבי שחזור, השלכות, וצילומי מסך מוטמעים
- `BUGS.md` — אותו מידע בקצרה
- `evidence/video/` — הקלטות מסך שמראות את השחזור לפני התיקון
- `evidence/img/` — צילומי מסך

חשד לבאג חמישי, לחיצה כפולה מהירה על התחלת המבדק, נבדק בשלושה תרחישים ונשלל.

כל באג מתועד עם סביבת הבדיקה המלאה, תנאי מקדים, שלבי שחזור מדויקים לפי שמות
הכפתורים בממשק, נתוני הבדיקה, תדירות השחזור, וההשלכה.

## אפיון המוצר

`PRODUCT_SPEC.md` מכיל את האפיון המלא של האפליקציה הנבדקת: הבעיה, קהל היעד,
עקרונות המוצר, אפיון מסכים, הלוגיקה החישובית מאחורי המדדים, שמירת הנתונים,
הדרישות הלא פונקציונליות, ומה מחוץ לגבולות הגרסה.
